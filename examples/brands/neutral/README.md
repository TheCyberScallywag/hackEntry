# examples/brands/neutral/

The template's neutral brand (CC0, see LICENSE): placeholder name, a plain palette and
placeholder images. To start a re-brand from it, copy this folder over `brand/`, replace the
placeholders and the images, then run `uv run task sync`; `uv run task test` fails until every
copy is current. `brand/README.md` describes each file and what `task sync` checks.

`content/` is template sample content that this application does not use.
